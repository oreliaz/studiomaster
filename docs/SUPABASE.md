# StudioMaster — הקמת שרת משותף (Supabase)

מדריך חד-פעמי להקמת השרת שמאחד את מאגר הידע בין כמה אולפנים. חינמי לחלוטין לשימוש רגיל.

## למה זה טוב
- **משתמש (חשבון) לכל אולפן** — כל אולפן נכנס עם אימייל וסיסמה משלו.
- **וורקספייס משותף** — מקבץ כמה אולפנים יחד, וכולם חולקים את אותו מאגר ידע (הערות פר-פודקאסט
  + מאגר באגים). מה שאולפן אחד לומד — כולם מרוויחים.

## שלב 1 — צור פרויקט Supabase (פעם אחת, ~3 דקות)
1. היכנס ל-**https://supabase.com** ולחץ **Start your project** (התחברות עם Google/GitHub).
2. **New project** → תן שם (למשל `studiomaster`), בחר סיסמה למסד הנתונים (שמור אותה), ואזור קרוב.
3. המתן שהפרויקט יוקם (דקה-שתיים).

## שלב 2 — הרץ את סכימת מסד הנתונים (פעם אחת)
1. בתפריט הצד של Supabase: **SQL Editor** → **New query**.
2. פתח את הקובץ [`../services/supabase/schema.sql`](../services/supabase/schema.sql), העתק את **כל** התוכן,
   הדבק בעורך, ולחץ **Run**. אמור להופיע "Success".

## שלב 3 — (מומלץ לפיילוט) בטל אימות אימייל
כדי שכל אולפן יוכל להתחבר מיד בלי ללחוץ על קישור במייל:
- **Authentication → Providers → Email** → כבה **Confirm email** → **Save**.
  *(אפשר להשאיר דלוק — אז אחרי "צור משתמש" צריך לאשר את המייל לפני התחברות.)*

## שלב 4 — העתק את פרטי החיבור
- בתפריט: **Project Settings → API**.
- העתק שני דברים:
  - **Project URL** (למשל `https://abcd1234.supabase.co`)
  - **anon public** key (מפתח ארוך).

## שלב 5 — חבר את StudioMaster
1. באפליקציה: לשונית **"מאגר ידע"** → כרטיס **"חשבון ושרת (Supabase)"**.
2. הדבק את ה-URL וה-anon key → **שמור הגדרות שרת**.
3. **צור משתמש לאולפן** (אימייל + סיסמה) — זה החשבון של האולפן הזה.
4. **צור וורקספייס** (למשל "האולפנים של אליעז"). יופיע **קוד הצטרפות**.

## שלב 6 — צרף אולפנים נוספים
בכל מחשב אולפן אחר: חזרו על שלב 5 (אותו URL + anon key, אבל **משתמש חדש** לכל אולפן),
ואז במקום "צור וורקספייס" — הזינו את **קוד ההצטרפות** ולחצו **הצטרף עם קוד**.

זהו. עכשיו לחיצה על **🔄 סנכרן** בלשונית "מאגר ידע" מסנכרנת את כל האולפנים דרך השרת
(מיזוג "העדכני מנצח"). ההרשאות (RLS) מבטיחות שכל אחד רואה רק את הוורקספייס שלו.

## הערות אבטחה
- ה-anon key מיועד לצד-לקוח (public) — מוגן ע"י Row-Level Security שהוגדר בסכימה.
- אסימוני ההתחברות נשמרים מוצפנים במחשב (safeStorage/DPAPI ב-Windows).
- אם אין שרת מוגדר — המערכת עדיין עובדת מקומית, ו-🔄 סנכרן נופל חזרה ל-Google Drive.
