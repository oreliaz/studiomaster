# apps/desktop

אפליקציית ה-Electron: ה-UI (React) וה-orchestrator (Main process).

## אחריות
- **Renderer (React)**: אשף פתיחת אולפן, Dashboard, Mixer View.
- **Main (Node/TS)**: מכונת-המצבים של Session, ניהול תת-המערכות (OBS, Launcher, Cloud, AI),
  גישה ל-SQLite.
